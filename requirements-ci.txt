# CI-only requirements. Use requirements.txt for local development.
#
# WHY THIS FILE EXISTS, measured rather than assumed:
# putting the jobcore git URL in requirements.txt CLOBBERS a local editable
# install. Verified on a clean venv 2026-08-20 -- after `pip install -e
# ../jobcore`, running `pip install -r <file with the git URL>` printed
# "Attempting uninstall: jobcore / Successfully uninstalled", the
# "Editable project location" line disappeared, and the __editable__ shim was
# replaced by a real jobcore/ directory. Reproduced twice. pip prints no
# "Requirement already satisfied" line for a direct-URL requirement, so the
# clobber is silent unless you go looking.
#
# Local iteration on jobcore matters more than CI convenience, so CI is the
# side that installs from git and requirements.txt stays editable-friendly.
#
# LOCAL DEVELOPERS: do not use this file. See requirements.txt.

-r requirements.txt

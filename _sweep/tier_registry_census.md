Note on the ORPHAN verdict and the repo's own decoy check.
`tests/test_no_decoys.py::TestEveryConfigConstantHasAReader` asserts every
`config.py` constant is read somewhere in the package, using the same
word-boundary regex this census uses -- but its `_reader_count(name,
exclude=CONFIG_PY)` excludes ONLY `config.py`, and its `_production_files()`
includes `naukri_server/healing/tier_registry.py`. So the registry entry
itself counts as a reader there. Any constant listed in the tier registry
satisfies that test even when nothing else in the package touches it, which
is why `AB_REVIEW_FILTERS_API` is green under the standing check and ORPHAN
here. This census excludes the registry, so it is the stricter instrument;
the two do not disagree about the facts, only about what counts as a reader.
